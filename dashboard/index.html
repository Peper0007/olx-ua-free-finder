Кнопка запускает GitHub Actions. Ей нужен токен GitHub — он хранится в базе дашборда и общий для обоих пользователей, вводить его нужно один раз. Создай его: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate: Repository access — Only select repositories → olx-ua-free-finder, Permissions → Repository → Actions: Read and write.
